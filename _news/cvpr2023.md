We are pleased to announce that the following three papers have been accepted at [CVPR 2023](https://cvpr2023.thecvf.com/):

* [Chen Feng](https://sites.google.com/view/mr-chenfeng) and [Ioannis Patras](http://www.eecs.qmul.ac.uk/~ioannisp/), **["MaskCon: Masked Contrastive Learning for Coarse-Labelled Dataset"](https://github.com/MrChenFeng/MaskCon_CVPR2023/)**, CVPR 2023.
* [Ioannis Maniadis Metaxas](https://maniadisg.github.io/), [Georgios Tzimiropoulos](https://ytzimiro.github.io/), [Ioannis Patras](http://www.eecs.qmul.ac.uk/~ioannisp/), **["DivClust: Controlling Diversity in Deep Clustering"](https://arxiv.org/abs/2304.01042)**, CVPR 2023. 
* Simone Barattin, [Christos Tzelepis](https://chi0tzp.github.io/), [Ioannis Patras](http://www.eecs.qmul.ac.uk/~ioannisp/), Nicu Sebe, **["Attribute-preserving Face Dataset Anonymization via Latent Code Optimization"](https://github.com/chi0tzp/FALCO)**, CVPR 2023 (Top 10%).
