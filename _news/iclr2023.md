# Overview

We propose an unsupervised factorisation of a dataset of pretrained generator's intermediate feature maps. This provides an intuitive separation into representations of an image's <strong>parts</strong> and <strong>appearances</strong>:

{% include figure.html path="assets/img/panda-news.svg" class="img-fluid" %}


The learnt semantic factors allow for:
<ul>
    <li><strong>Local image editing</strong>: precise <em>pixel-level</em> control not facilitated by the SOTA.</li>
    <li><strong>Context-aware object removal</strong>: a single appearance factor removes objects in a scene.</li>
    <li><strong>Concept localization</strong>: the appearance factors localize semantic concepts in the image, such as the sky, skin, or background.</li>
</ul>
